CÓMO RESTAURAR ESTA VERSIÓN:
═════════════════════════════

Opción 1 - Restaurar archivos (si tienes el código fuente):
  1. Copiar app.js → src/renderer/app.js
  2. Copiar index.html → src/renderer/index.html
  3. Copiar main.js → src/main/main.js
  4. Ejecutar: npm start

Opción 2 - Usar el ejecutable ya compilado:
  Ubicación del .exe:
  dist\Tienda Katarata-win32-x64\Tienda Katarata.exe

Opción 3 - Clonar desde GitHub:
  git clone https://github.com/CristFS/tienda-katarata.git
